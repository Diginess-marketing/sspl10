❌ Common Errors and Fixes

1. No logs appear at all:
  • Console tab is not selected (click "Console" in DevTools)
  • Console is filtered - click the filter icon and select "All levels"
  • Page didn't load - check the URL is correct
2. Error: "PGRST116" or "new row violates row-level security":
  • RLS (Row Level Security) is blocking database access
  • Run the SQL file: DIAGNOSE_PLAYER_REGISTRATIONS.sql in Supabase
  • Check if policies allow SELECT for authenticated users
3. Error: "Failed to fetch" or network error:
  • Supabase connection issue
  • Check .env file has correct VITE_SUPABASE_URL
  • Verify internet connection
4. Query returns 0 rows but no error:
  • Table is empty - no data in player_registrations
  • Or RLS is silently filtering all rows
Step 4: Copy Console Output
Right-click in the Console → "Save as..." to save all logs
Or manually copy the relevant error messages
